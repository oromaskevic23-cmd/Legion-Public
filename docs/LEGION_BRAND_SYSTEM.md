## Visual identity specification

- **Primary:** near-black midnight background (#07101E), deep navy (#0B1B32).
- **Intelligence accent:** electric azure (#169BFF), for data-flow and coordinated teams.
- **Authority accent:** restrained metallic gold (#D6AE55), reserved for titles, formal attribution and the canonical license seal.
- **Text:** off-white (#F4F7FB), muted silver (#A8BAD0).
- **Symbol direction:** a clean geometric command shield containing connected agent nodes, forming a coherent formation rather than an aggressive military insignia.
- **Official imagery:** professional, diverse digital specialists connected to orchestrated task networks. No implied real human employees or fabricated client relationships.
- **Typography:** readable contemporary sans-serif body with restrained premium display lettering.
- **GitHub:** English-only technical documents. Translation and language selection are restricted to the official multilingual websites.

**Canonical IMPERIAL Core cryptographic license seal:** when an illustration includes the existing Owner-approved seal, reuse the same source asset **unchanged**, including the approved crown and the handwritten RomaskevicH signature. Do not redraw the crown, alter the license wording, change the owner name or use a decorative image as proof of a valid signed entitlement. A brand seal is not a cryptographic certificate.
